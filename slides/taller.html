Taller 2026

Objetivos

  • Leer y depurar datos de cajas verdes (VMS GPS-GPRS de la flota artesanal andaluza)
  • Unirlos con las notas de venta para asignar un arte a cada ping
  • Identificar el estado de pesca con filtros de velocidad por arte
  • Calcular el esfuerzo (horas de pesca) en una grilla 0.05° con código C-square

Todos los datos del taller son simulados (data/simular_datos.R). Mismo formato que los ficheros de la Junta de Andalucía, sin barcos, posiciones ni ventas reales.

Datos

Cajas verdes: formato bruto

Un CSV por año, separador ;, BOM UTF-8, fecha dd/mm/aaaa:

## FECHA;HORA;CFPO;VELOCIDAD;LATITUD;LONGITUD;RUMBO;¿EN PUERTO?
## 02/01/2023;05:26:56;999009;0.07;36.79508;-6.43002;297.8;1
## 02/01/2023;05:29:26;999009;0.05;36.79491;-6.43001;159.5;1
## 02/01/2023;05:31:56;999009;0;36.79496;-6.42991;357;1
## 02/01/2023;05:34:26;999009;0.1;36.79503;-6.42989;313.3;1
## 02/01/2023;05:36:58;999009;0.17;36.79513;-6.42997;125.1;1
  • CFPO: código del barco en el Censo de Flota Pesquera Operativa
  • VELOCIDAD (nudos) y RUMBO: instantáneos, reportados por la caja
  • ¿EN PUERTO?: 1 si el ping está en puerto

01 · Lectura

01_load_CV.R

read_cv <- function(path, year) {
  f1 <- file.path(path, paste0("Resultado_2_CAJAS_NUEVAS_", year, ".csv"))
  dt <- fread(f1, sep = ";", dec = ".", encoding = "UTF-8")
  setnames(dt, grep("PUERTO", names(dt), value = TRUE), "EN_PUERTO")
  dt <- dt[LATITUD  >= lat_min & LATITUD  <= lat_max &
           LONGITUD >= lon_min & LONGITUD <= lon_max]
  dt[, ANYO := year]
  dt
}
CV_all <- rbindlist(lapply(anyos, function(yr) read_cv(path_cv, yr)))
  • fread es rápido para decenas de millones de filas (los datos reales: ~67 M)
  • Filtrar la zona al leer reduce memoria y elimina pings con error de GPS (0, 0)

02 · Formato

02_format_CV.R: velocidad e intervalo entre pings

setorder(CV_all, VE_REF, SI_TIMESTAMP)
CV_all[, fecha_dia := as.Date(SI_TIMESTAMP, tz = "Europe/Madrid")]
CV_all[, `:=`(
  SI_DISTANCECA = c(NA, distHaversine(cbind(LONGITUD[-.N], LATITUD[-.N]),
                                      cbind(LONGITUD[-1],  LATITUD[-1]))),
  SI_TDIFF      = c(NA, as.numeric(diff(SI_TIMESTAMP), units = "secs"))
), by = .(VE_REF, fecha_dia)]
CV_all[, SI_SPCA := SI_DISTANCECA / SI_TDIFF * 1.94384]   # m/s → nudos
  • Ordenar antes de calcular diferencias
  • Agrupar por barco y día: no unir el último ping de un día con el primero del siguiente
  • FT_REF = barco + día: es la “marea” que luego se cruza con las notas de venta

Intervalo entre pings

Dos tipos de caja (~150 s y ~190 s), pings perdidos (cola larga) y transmisiones muy seguidas (< 60 s).

Velocidad calculada fuera de puerto

Distribución bimodal: pesca (< 3 nudos) y navegación (7–9 nudos).

Velocidad por arte y umbrales de pesca

04_effort_grid.R: grilla y C-square

res <- 0.05
CV_fil[, lon_cel := floor(SI_LONG / res) * res + res / 2]
CV_fil[, lat_cel := floor(SI_LATI / res) * res + res / 2]
centroides[, csq := csquare.cod(lon_cel, lat_cel, degrees = res)]

esfuerzo <- CV_fil[, .(horas_pesca = sum(SI_TDIFF) / 3600,
                       n_barcos    = uniqueN(VE_REF)),
                   by = .(lon_cel, lat_cel, csq, ANYO, LE_MET4)]
  • Esfuerzo = Σ Δt de los pings en estado de pesca
  • C-square: código estándar ICES para intercambiar datos por celda
